# Проект «Самолёты» (курсовая работа)

Программа получает данные о самолётах в воздушном пространстве выбранной страны (Nominatim + OpenSky), фильтрует и сортирует их и сохраняет в JSON-файл.

## Запуск в PyCharm
1. Откройте папку проекта и создайте виртуальное окружение; установите зависимости: `pip install -r requirements.txt` (или кнопка «Install requirements» в `requirements.txt`).
2. Запустите `main.py`.
3. Тесты и покрытие: `pytest`.

## Структура
- `src/api.py` — абстрактный `BaseAPI` и `AeroplanesAPI`
- `src/aeroplane.py` — класс `Aeroplane` (валидация, сравнение по высоте и скорости)
- `src/saver.py` — абстрактный `BaseSaver` и `JSONSaver`
- `src/utils.py` — фильтрация, сортировка, топ N, вывод
- `main.py` — консольное взаимодействие
- `tests/` — тесты (покрытие 100 %)
